## Add text

Add some text to your webpage in `Column 1`.

```html filename="index.html" line_numbers="true" line_number_start="8" line_highlights="10"
<h1>My magazine</h1>
<div class="column1">
    Welcome to the kitten fan page where you will learn all about these cute furry animals.
</div>
```

## Now run your code

Check that the first column now shows your welcome text.
