## Add columns

Websites often use multiple columns to space out the content. Create a two-column layout for your magazine.

First, add the columns in HTML. Select the `index.html` file and add this code to create two columns. 

```html filename="index.html" line_numbers="true" line_number_start="7" line_highlights="9-14"
<body>
<h1>My magazine</h1>
<div class="column1">
	Column 1
</div>
<div class="column2">
	Column 2
</div>
</body>

```

## Now run your code

See the text in two columns. They need to be styled with CSS to have a two-column layout.
